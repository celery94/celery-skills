# Xiaohongshu publish flow reference

本文件提供给 `xiaohongshu-publisher` skill 作为实现细则参考，目标是让浏览器自动化更稳健，而不是依赖单一脆弱选择器。

## 固定入口

- 发布页：`https://creator.xiaohongshu.com/publish/publish?from=tab_switch&target=image`
- 目标内容类型：图文 / image post

## 自动化原则

1. 优先用 **可见文本、表单语义、稳定属性** 定位元素
2. 避免依赖易变化的哈希 class 名
3. 每一步都先确认页面状态，再继续下一步
4. 真正点击“发布”前，必须确认按钮语义和当前页面上下文

## 登录检测信号

以下信号任一成立，可视为未完成登录：

- URL 不在创作者发布上下文，且出现登录跳转
- 页面主区域出现登录按钮、手机号输入、验证码输入、扫码登录提示
- 发布区不可见或无法交互，只剩登录引导

处理：

1. 停止自动化
2. 提示用户在当前 auto-connected Chrome 中完成登录
3. 登录完成后重新确认页面位于发布页

## 图片收集规则

如果输入是目录：

1. 先找 `card-*.png`
2. 如果不存在，再找 `card.png`
3. 再回退到目录下所有 `.png`, `.jpg`, `.jpeg`, `.webp`
4. 结果按自然排序 / 文件名升序

如果输入是显式图片列表：

- 保持用户提供顺序
- 过滤掉不存在的文件并直接报错

## 上传策略

1. 先得到**最终完整且有序**的图片列表，不要边上传边继续收集
2. 找到一个稳定的上传入口或一个稳定的文件输入框
3. 在**一次文件选择 / 一次设置文件**动作里提交全部图片路径
4. 上传后只等待这一整批图片完成，不要为同一条笔记再逐张重开文件选择器

## 字段填写策略

### 标题

- 优先寻找带“标题”语义或占位提示的输入控件
- 写入后再次读取页面值，确认已成功填入

### 正文

- 优先寻找正文编辑区、内容编辑器或可编辑文本区域
- 填写后确认文本在页面中可见

### 话题

- 若页面提供显式话题输入交互，优先使用
- 插入每个话题时尽量匹配候选项
- 若候选不存在或交互失败，把带空格分隔的 tag 文本追加到正文末尾，保证最终文本仍保留话题语义
- tag 追加格式必须是：每个 tag 前都有空格，多个 tag 之间用空格分隔，例如 ` #AI #增长策略`
- 如果正文末尾没有空白，先补一个空格，再追加第一个 tag；不要把 tag 紧贴在正文最后一个字后面

## 上传完成信号

至少满足以下之一：

- 上传列表中每张图片都出现稳定缩略图
- 页面显示上传完成而无失败提示
- 文件输入框处理结束，且图片区域数量与待上传数量一致

补充要求：

- 缩略图数量必须和本次整批上传的目标数量一致
- 在上传完成前，不要再次触发上传入口或再次设置文件

## 禁止发布的信号

任一成立都不要点击“发布”：

- 页面出现红字错误或校验消息
- 仍有图片在上传中
- 标题或正文为空
- 页面离开目标发布上下文
- “发布”按钮禁用

## 成功信号

任一成立可视为发布成功：

- 成功 toast / 成功提示语
- 跳转到作品管理 / 笔记列表 / 内容详情
- 页面显示发布成功或作品已生成

## 失败信号

常见失败包括：

- 登录失效
- 图片格式或数量不符合页面要求
- 文案过长或触发内容校验
- 频繁操作导致按钮锁定
- 页面弹出额外必填项

出现失败时，应优先向用户报告页面原始报错，而不是猜测原因。
